# 01 — Personal Portfolio (Dheeraj T.P)

Master plan: none (this repo has no `docs/PLAN.md`; plan 01 is the only plan) · Builds on: nothing · Rules: [`../../../CLAUDE.md`](../../../CLAUDE.md), `.ai/`, `rules/frontend/CLAUDE_FRONTEND.md`

Design reference (approved, interactive HTML): [`design/reference.html`](design/reference.html). Images and logos: [`design/assets/`](design/assets/). Published copy: https://claude.ai/artifact/42t9fRnoGrQET4uZFKEyMg

## Goal
- A fast, frontend-only React portfolio for a full-stack developer and team lead, replacing the 4-year-old site.
- Hiring managers see in one scroll: who Dheeraj is, where he worked, five case studies, featured projects, how he leads, how he works with AI, awards, education, skills and contact.
- Content is edited in plain data files and redeployed. No backend, no database, no admin screen.

## Decisions (already made; do not revisit)
