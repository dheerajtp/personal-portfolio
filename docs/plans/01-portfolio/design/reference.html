How I lead

I lead four developers across Python, Laravel, React.js and Node.js. The job is to keep the work clear, ordered and moving.

Clear tasksI turn client requirements from analysts and project managers into technical tasks the team can pick up.
PrioritiesI set development priorities so the most important milestone is always the one in progress.
UnblockingI resolve delivery challenges early, before they turn into missed dates.
CommunicationI keep communication clear across projects, so everyone knows what is happening and why.

Client projects are confidential, so this section describes how I work rather than naming clients or quoting project counts.

AI-assisted workflow

Claude Code and agent skills are part of how I plan, build and review. Every change moves through the same six steps, and nothing ships without review. I even built a tool to watch my agents work: Agent Office, in the case studies above.

Understand

Turn the requirement into a written spec with acceptance checks.

  • Spec
  • Acceptance criteria

Investigate

Read the real repository first and reuse what already exists.

  • Repo survey
  • Reuse over rewrite

Approve

Agree the scope before any file changes. The plan is the contract.

  • Approval gate

Build

Implement only the approved scope, in small slices that can run in parallel.

  • Claude Code
  • Agent skills
  • Small slices

Code review

AI reviews the diff for bugs, security issues and standards before I do. Then I read every change myself, and nothing merges until both passes are clean.

  • AI diff review
  • Security check
  • Standards check
  • Human review

Verify

Run tests, lint and a real browser check, then ship.

  • Tests
  • Lint
  • Browser check
